🔤 What is JSX?
JSX (JavaScript XML) is a syntax extension for JavaScript that lets you write HTML-like code inside JavaScript.

It makes your code easier to write and understand when working with UI.

✅ Example: JSX vs JS
Instead of doing this in JavaScript:

const element = document.createElement("h1");
element.innerText = "Hello World";
document.body.appendChild(element);

With JSX, you simply do:
const element = <h1>Hello World</h1>;


🔍 JSX Rules to Remember
1)Return only one root element

// ❌ Invalid
return <h1>Hello</h1><p>World</p>

// ✅ Valid (wrap with a div or fragment)
return (
  <>
    <h1>Hello</h1>
    <p>World</p>
  </>
)

2)Use className instead of class

// HTML: <div class="box">
<div className="box">


3)Use {} for JavaScript inside JSX
const name = "Jatt";
return <h1>Hello, {name}!</h1>


4)Self-closing tags must end with /
<img src="logo.png" alt="logo" />


🛠 Task: Modify Your App.jsx

Now try this in your App.jsx:
function App() {
  const name = "Jatt";
  const age = 21;

  return (
    <>
      <h1>Hello, {name}!</h1>
      <p>You are {age} years old.</p>
    </>
  );
}

export default App;

Then save and see the output on your browser.
