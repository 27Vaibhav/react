function customRender(reactElement, container){
    /*
    const domElement = document.createElement(reactElement.type)
    domElement.innerHTML = reactElement.children
    domElement.setAttribute('href', reactElement.props.href)
    domElement.setAttribute('target', reactElement.props.target)

    container.appendChild(domElement)
    */

    const domElement = document.createElement(reactElement.type)
    domElement.innerHTML = reactElement.children
    for (const prop in reactElement.props) {
        if (prop === 'children') continue;
        domElement.setAttribute(prop, reactElement.props[prop])
    }
    container.appendChild(domElement)
}

🧠 What is this code doing?
function customRender(reactElement, container) { ... }

1)You're defining a custom render function that:
2)Takes a reactElement object (which mimics the JSX-like structure).
3)Creates a real DOM element based on the type (like 'a' for <a>).
4)Assigns props like href, target, etc., using setAttribute.
5)Sets inner HTML using the children property.
6)Appends the DOM element to the container (#root in this case).


📦 Sample Input
const reactElement = {
  type: 'a',
  props: {
    href: 'https://google.com',
    target: '_blank'
  },
  children: 'Click me to visit google'
}

This object represents the following JSX:
<a href="https://google.com" target="_blank">
  Click me to visit google
</a>


🧱 Breakdown of customRender

const domElement = document.createElement(reactElement.type)
➡️ Creates an actual DOM element like <a>


domElement.innerHTML = reactElement.children
➡️ Sets the text inside the element


for (const prop in reactElement.props) {
  if (prop === 'children') continue;
  domElement.setAttribute(prop, reactElement.props[prop])
}
➡️ Loops through the props and adds them as attributes (href, target)


container.appendChild(domElement)
➡️ Finally appends it to the actual DOM (e.g. inside #root)


🎯 Why is this important in the context of React?
This is React at its core — it:

Takes JSX (or object form).

Converts it to a virtual representation (like your object).

Transforms it into real DOM nodes.

Efficiently updates the DOM when data changes (your code doesn’t do that part — React does).


✅ Summary
Your customRender is a miniature React renderer that shows:

How JSX is just objects.

How these objects are used to create and update the DOM.

Why React is powerful — it builds on this foundation with smart updates, state management, and more.


At its heart, React works like this:

JSX is compiled into JavaScript objects (what you're calling reactElement).
These objects describe what the UI should look like.
A renderer (like ReactDOM) takes those objects and:
Creates real DOM elements,
Applies props (attributes),
Injects them into the page.
You're mimicking that with your customRender() function.
